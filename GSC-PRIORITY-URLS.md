## Для кожного URL зафіксувати

- чи URL відомий Google;
- чи дозволене індексування;
- canonical, який обрав Google;
- останній crawl;
- статус індексації;
- impressions / clicks / CTR / average position;
- основні queries;
- чи є покази без кліків;
- чи є сторінка з тим самим intent, яка конкурує з нею.

## Порядок дій після отримання даних

1. Спочатку виправити сторінки, які Google обходить, але не індексує.
2. Потім сторінки з impressions і низьким CTR: title/description/snippet.
3. Потім сторінки з позиціями приблизно 5–20: контент, internal links, case evidence.
4. Не створювати масово нові статті, поки не зрозуміло, як працюють уже опубліковані 100 матеріалів.
